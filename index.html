Turn on cloud short-links ☁️

Stores work offline already. To get short shareable links + photos that load everywhere, connect a free Supabase project (2 min, no card):

1
Go to supabase.com → sign up → New project (pick any name + password).
2
Open Project Settings → API. Copy the Project URL and the anon public key.
3
Send both to HolyByte and we wire it in — then every store gets a short link automatically.

The anon key is safe to use in a browser app — it's designed for exactly this.
